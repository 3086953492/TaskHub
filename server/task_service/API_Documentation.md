# TaskHub 任务管理系统 API 文档

## 概述

TaskHub 是一个任务管理系统，提供任务的创建、分配、查看、更新等功能。所有API都需要身份验证，使用JWT Token进行认证。

## 认证

所有API请求都需要在请求头中包含认证Token：

```
Authorization:  <JWT_TOKEN>
```

## 基础URL

```
http://localhost:8080
```

## 响应格式

### 成功响应格式

```json
{
  "code": 200,
  "msg": "操作成功消息",
  "data": {}  // 可选，包含具体数据
}
```

### 错误响应格式

```json
{
  "code": 400,  // HTTP状态码
  "msg": "错误描述信息"
}
```

## API接口

### 1. 创建任务

**接口地址：** `POST /task`

**描述：** 创建一个新的任务

**请求参数：**

```json
{
  "title": "任务标题",
  "description": "任务描述",
  "priority": 1,
  "due_date": "2024-12-31T23:59:59Z",
  "images": [
    {
      "url": "图片URL地址"
    }
  ]
}
```

**参数说明：**
- `title` (string, 必填): 任务标题
- `description` (string, 可选): 任务描述
- `priority` (int, 必填): 优先级，1-高优先级，2-中优先级，3-低优先级
- `due_date` (string, 可选): 截止日期，ISO 8601格式
- `images` (array, 可选): 任务相关图片

**成功响应：**
```json
{
  "code": 200,
  "msg": "任务创建成功"
}
```

**错误响应：**
- `400`: 参数错误
  ```json
  {
    "code": 400,
    "msg": "参数错误: 具体错误信息"
  }
  ```
- `500`: 服务器内部错误
  ```json
  {
    "code": 500,
    "msg": "任务创建失败"
  }
  ```

**接口地址：** `PATCH /task?id={task_id}`

**描述：** 将任务分配给当前用户

**查询参数：**

**成功响应：**
```json
{
  "code": 200,
  "msg": "任务分配成功"
}
```

**错误响应：**
- `400`: 无效的任务ID

  ```json
  {
  ```

- `500`: 服务器内部错误
  ```json
  {
    "code": 500,
  ```

### 3. 获取任务列表

**接口地址：** `GET /task`

**描述：** 获取任务列表，支持分页和筛选

**查询参数：**
- `page` (uint, 必填): 页码
- `page_size` (uint, 必填): 每页数量
- `assignee_id` (uint, 可选): 分配人ID筛选
- `creator_id` (uint, 可选): 创建人ID筛选

**权限说明：**
- 管理员用户可以查看所有任务
- 普通用户只能查看自己创建或被分配的任务
- 必须至少提供一个筛选条件（assignee_id或creator_id）

**成功响应：**
```json
{
  "code": 200,
  "msg": "获取任务列表成功",
  "data": [
    {
      "task_id": 1,
      "status": 1,
      "created_at": "2024-01-01T10:00:00Z",
      "title": "任务标题",
      "priority": 1,
      "due_date": "2024-12-31T23:59:59Z"
    }
  ]
}
```

**状态说明：**
- `1`: 待处理
- `2`: 进行中
- `3`: 已完成
- `4`: 已取消

**错误响应：**
- `400`: 无效的页码或页大小
  ```json
  {
    "code": 400,
    "msg": "无效的页码" // 或 "无效的页大小" 或 "无效的分配人ID" 或 "无效的创建人ID"
  }
  ```
- `403`: 无权限查看任务列表
  ```json
  {
    "code": 403,
    "msg": "无权限查看其他人的任务" // 或 "无权限查看任务列表"
  }
  ```
- `500`: 服务器内部错误
  ```json
  {
    "code": 500,
    "msg": "获取任务列表失败"
  }
  ```

### 6. 更新任务

**接口地址：** `PATCH /task/{id}`

**描述：** 更新任务信息，包括基本信息和图片

**路径参数：**
- `id` (uint, 必填): 任务ID

**请求参数：**
```json
{
  "status": 1,
  "update_task_info": {
    "title": "新任务标题",
    "description": "新任务描述",
    "priority": 2,
    "due_date": "2024-12-31T23:59:59Z"
  },
  "update_images": [
    {
      "id": 1,
      "url": "新图片URL",
      "sort_order": 1
    }
  ],
  "delete_images": [
    {
      "id": 2
    }
  ],
  "add_images": [
    {
      "url": "新增图片URL",
      "sort_order": 2
    }
  ],
  "remark": "更新备注",
  "remark_images": [
    {
      "url": "备注图片URL"
    }
  ]
}
```

**参数说明：**
- `status` (int, 可选): 任务状态，1-待处理，4-已取消
- `update_task_info` (object, 可选): 更新的任务基本信息
- `update_images` (array, 可选): 更新现有图片
- `delete_images` (array, 可选): 删除指定图片
- `add_images` (array, 可选): 新增图片
- `remark` (string, 可选): 操作备注
- `remark_images` (array, 可选): 备注相关图片

**成功响应：**
```json
{
  "code": 200,
  "msg": "任务更新成功"
}
```

**错误响应：**
- `400`: 无效的任务ID或参数错误
  ```json
  {
    "code": 400,
    "msg": "无效的任务ID" // 或 "参数错误: 具体错误信息"
  }
  ```
- `500`: 服务器内部错误
  ```json
  {
    "code": 500,
    "msg": "任务更新失败"
  }
  ```

## 数据模型

### 任务状态枚举
- `1`: 待处理
- `2`: 进行中  
- `3`: 已完成
- `4`: 已取消

### 任务优先级枚举
- `1`: 高优先级
- `2`: 中优先级
- `3`: 低优先级

### 权限说明
- **管理员用户（admin）**: 可以查看和操作所有任务
- **普通用户**: 只能查看和操作自己创建或被分配的任务

### 时间格式
所有时间字段都使用ISO 8601格式：`2024-01-01T10:00:00Z`

## 错误码说明

| HTTP状态码 | 说明 |
|------------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未授权，需要有效的认证Token |
| 403 | 禁止访问，权限不足 |
| 500 | 服务器内部错误 |
